Adaptive question blocks

The agent asks only for what's missing, choosing one block per question. Each block has a “Why we ask” line and, where it helps, “I don't know”. The header says “Question 2 of 3” only when the remaining count is certain; otherwise “A quick detail”. Every block also accepts a spoken answer, confirmed before use. Confirming information is separate from consenting to save.
